# ALMOGHANI LIVE — تجربة الواجهة

واجهة ترفيه عربية RTL متجاوبة مستوحاة من المراجع المرفقة: هيكل كرومي فضي بلمسات داكنة، أقسام للأفلام والمسلسلات والبث المباشر والرياضة، ومكتبة بطاقات للمحتوى.

## التفاعل

- التنقل بين الأقسام وتصفيتها حسب الأصل.
- البحث الفوري وعرض حالة عدم وجود نتائج.
- إضافة العناوين إلى المفضلة وحفظها محلياً في المتصفح.
- فتح نافذة معاينة من البطاقات أو من زر «شاهد الآن».
- قائمة متجاوبة للشاشات الصغيرة، وأزرار ترقيم عند تعدد النتائج.

المشروع نموذج واجهة ثابت المحتوى؛ لا يتصل بخدمة بث ولا يضم بيانات مباريات حقيقية. صور العناوين تجريبية. صورة المدينة مأخوذة من [Unsplash](https://unsplash.com/s/photos/night-skyline).
